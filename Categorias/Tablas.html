Tablas

Las tablas en HTML se utilizan para organizar y presentar datos de manera estructurada. Una tabla se compone de filas y columnas, donde cada intersección de una fila y una columna se llama celda. Las tablas son útiles para mostrar información tabular, como horarios, precios, resultados de encuestas, entre otros.

Elementos de una tabla:

  • <table>: Es el elemento contenedor que define la tabla.
  • <thead>: Define el encabezado de la tabla, que generalmente contiene las etiquetas de las columnas.
  • <tbody>: Define el cuerpo de la tabla, donde se colocan las filas de datos.
  • <tr>: Define una fila en la tabla.
  • <th>: Define una celda de encabezado en la tabla, que generalmente se muestra en negrita y centrada.
  • <td>: Define una celda de datos en la tabla, que contiene la información que se desea mostrar.
