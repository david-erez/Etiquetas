Listas

Las listas son una forma de organizar información en HTML utilizandose mallormente para agrupar elementos relacionados. Hay dos tipos principales de listas: ordenadas y desordenadas.

Tipos de listas

  • Listas desordenadas: Se crean utilizando la etiqueta <ul> y cada elemento de la lista se define con la etiqueta <li>. Las listas desordenadas se representan con viñetas.
    • Ejemplo de lista desordenada:
  • li representa un elemento de una lista, y se utiliza tanto en listas ordenadas como desordenadas para definir cada ítem de la lista.
    • elemento 1
    • elemento 2
    • elemento 3
  • dl representa una lista descriptiva, que se utiliza para definir términos y sus descripciones. Dentro de una lista descriptiva, dt se utiliza para definir el término, mientras que dd se utiliza para proporcionar la descripción del término.
    • Ejemplo de lista descriptiva:
    HTML
    Lenguaje de marcado para crear páginas web.
    CSS
    Lenguaje de estilos para diseñar páginas web.
  • Listas ordenadas: Se crean utilizando la etiqueta <ol> y cada elemento de la lista se define con la etiqueta <li>. Las listas ordenadas se representan con números o letras.
    • Ejemplo de lista ordenada:
    1. Primer elemento
    2. Segundo elemento
    3. Tercer elemento
