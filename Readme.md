Estructurales

 html = Es la raíz del documento. Contiene todo el contenido de la página.

 head = Contiene información técnica (metadatos, título, enlaces CSS, scripts).

 body = Contiene todo lo visible de la página.

 header = Define el encabezado de una página o sección.

 nav = Contiene enlaces de navegación.

 main = Indica el contenido principal del documento.

 section = Agrupa contenido relacionado temáticamente.

 article = Representa contenido independiente (noticia, post, artículo).

 aside = Contenido complementario (barra lateral, notas).

 footer = Pie de página o sección.

📝 Texto

 h1   a  h6 = Encabezados jerárquicos.  h1   es el más importante.

 p = Define un párrafo.

 strong = Indica importancia semántica (se muestra en negrita).

 em = Indica énfasis semántico (se muestra en cursiva).

 span = Contenedor en línea sin significado semántico.

 br = Salto de línea.

 hr = Línea horizontal para separar contenido.

📋 Listas

 ul = Lista desordenada (viñetas).

 ol = Lista ordenada (numerada).

 li = Elemento de una lista.

 dl = Lista descriptiva.

 dt = Término en lista descriptiva.

 dd = Descripción del término.

🧾 Formularios

 form = Contenedor del formulario.

 label = Etiqueta descriptiva para un campo.

 input = Campo de entrada de datos (texto, email, password, etc.).

 textarea = Campo para texto largo.

 select = Lista desplegable.

 option = Opción dentro de un  select . 

 button = Botón interactivo (enviar, reset, acción).

📊 Tablas

 table = Contenedor de una tabla.

 thead = Encabezado de la tabla.

 tbody = Cuerpo de la tabla.

 tr = Fila.

 th = Celda de encabezado.

 td = Celda de datos.

🎬 Multimedia

 img = Inserta una imagen.

 audio = Inserta un archivo de audio.

 video = Inserta un video.

 iframe = Inserta contenido externo (YouTube, mapas, etc.).

 figure = Agrupa contenido multimedia con descripción.

 figcaption = Descripción de un  figure .
